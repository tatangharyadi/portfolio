# portfolio

Personal site ([tatangharyadi.github.io](https://tatangharyadi.github.io), served from
`index.html`/`style.css`) plus a writing workspace for articles published to Medium and
dev.to. Each article backlinks to the site, building personal SEO.

## Structure

- `index.html`, `style.css` — the portfolio site itself.
- `writing/` — the `ghostwriter` plugin's workspace: voice persona, drafts, and
  published articles. See `AGENTS.md` for the skill workflow.
- `plugins/ghostwriter/` — the Claude Code plugin that drafts and edits articles to
  read in one specific voice instead of generic AI prose.
