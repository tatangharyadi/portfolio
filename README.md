# portfolio

A writing workspace for articles published to Medium and dev.to. Each article
backlinks to [tatangharyadi.github.io](https://tatangharyadi.github.io), building
personal SEO.

## Structure

- `writing/` — the `ghostwriter` plugin's workspace: voice persona, drafts, and
  published articles. See `AGENTS.md` for the skill workflow.
- `plugins/ghostwriter/` — the Claude Code plugin that drafts and edits articles to
  read in one specific voice instead of generic AI prose.
